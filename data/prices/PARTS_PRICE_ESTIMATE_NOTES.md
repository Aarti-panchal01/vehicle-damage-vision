# Parts price coverage update

The table is normalized to 26 Contract A part names for each of five models (130 rows). Existing source-backed values from the prior table are retained where a matching part was available. Missing values are filled with transparent proxy estimates based on available comparable-model/part values and a simple model factor.

**Important:** rows marked `ESTIMATED_PROXY_NOT_VERIFIED` are development/demo estimates only. They are not OEM quotations, dealer quotations, garage quotes, or insurance-approved values. Do not represent them as verified prices. Confirm fitment by VIN/variant and replace estimates with dated source-backed quotations before a real claim.

The current labour and paint tables are not fully populated for all five models. A complete 130-row parts table therefore does not mean all repair estimates are fully priced. The calculator should continue to report missing labour/paint as unpriced rather than silently inventing those charges.
